API documentation

All Agent Data Co feeds as JSON, refreshed daily (~05:20 UTC). Base URL https://agentdataco.com. Machine-readable spec: /openapi.json.

Authentication

Send your key in the Authorization header: Authorization: Bearer adc_live_…. Keys are emailed automatically right after checkout. Get a key: Starter $19/month (latest data + 30-day history) or Pro $49/month (full archive, trends, priority watchlist, 100k requests).

Query parameters

  • limit — rows to return, 1–1000 (default 100)
  • offset — pagination offset (default 0)
  • since — ISO 8601 date/time; only rows on/after it (e.g. 2026-10-01)
  • q — case-insensitive text match across all fields

History & trends

Every daily snapshot is archived permanently. Query an entity's daily time series (metrics + rank) or the day's top movers:

curl -H "Authorization: Bearer $ADC_KEY" \
  "https://agentdataco.com/api/v1/github-ai-repos/history?entity=modelcontextprotocol/servers&from=2026-10-01"

curl -H "Authorization: Bearer $ADC_KEY" \
  "https://agentdataco.com/api/v1/trends?window=7d&feed=hf-trending"

History depth by plan: Starter last 30 days, Pro full archive ($49/month). Trends include 1d/7d/30d movers by stars/likes/points and events: new entities, LLM price changes, MCP version bumps, pricing-page changes. Public summary: /trends.

History rules: one entity per request (no whole-feed history); max 90-day window between from and to; limit 1–90 rows per page (default 31), follow nextCursor via cursor=. Past-date trends need feed=.

MCP server (for AI agents)

Remote MCP endpoint, Streamable HTTP: https://agentdataco.com/mcp. Free tools work without a key: list_feeds, get_sample, lookup_entity. Full tools need your API key as Authorization: Bearer adc_live_…: get_github_ai_repos, get_show_hn_ai, get_mcp_servers, get_hf_trending, get_llm_pricing, get_ai_pricing, get_history, get_trends. Calls count toward your monthly request quota; get_history/get_trends also count toward the daily history/trends cap.

Entity pages

Public pages with latest metrics and history for ~2,000 top entities, rebuilt daily: /repo/<owner>/<name>, /mcp/<server>, /llm/<provider>/<model>, /pricing/<vendor>, /hf/<type>/<id>. Index: sitemap.xml.

Request coverage

Need a pricing page or repo we don't track? Ask for it: /api/v1/ai-pricing?url=https://example.com/pricing or /api/v1/github-ai-repos?repo=owner/name. Untracked entities are added to our watchlist and collected from the next daily run.

Limits & errors

Starter includes 10,000 requests per calendar month (UTC); remaining quota is returned in X-RateLimit-Remaining. Fair use (history + trends): Starter 200 calls/day, Pro 1,000 calls/day per key (UTC day; remaining in X-History-Daily-Remaining). Keys that request many distinct entities or dates abnormally fast (bulk scanning) are throttled for 1 hour. Bulk/full-archive access needs a data licence (from $499/month, hello@agentdataco.com). Data may not be resold, redistributed or used to rebuild a competing dataset (terms). Errors: 401 missing/invalid/revoked key, 429 monthly limit, daily history limit (daily_history_limit) or extraction throttle (velocity_throttled, see Retry-After), 400 bad parameter, 503 feed temporarily unavailable. Cancelling your subscription revokes the key. Lost your key or need more volume? hello@agentdataco.com.
